# Identity & JWT Authentication

Bu proje, ASP.NET Core kullanılarak geliştirilmiş, güvenli kimlik doğrulama ve yetkilendirme altyapısı sunan bir web uygulamasıdır.
Özellikler:
*   **ASP.NET Core Identity:** Kapsamlı kullanıcı ve rol yönetimi.
*   **JWT (JSON Web Token):** Güvenli, token bazlı kimlik doğrulama altyapısı.
*   **Şifre Sıfırlama:** E-posta entegrasyonu ile kullanıcılara şifre yenileme bağlantısı gönderme.
*   **Rol Bazlı Yetkilendirme:** Admin ve standart kullanıcılar için farklı erişim izinleri ve sayfa yönlendirmeleri.
*   **Kullanıcı Yönetimi:** Admin panelinden kullanıcıların yetkilerini (rol) anlık olarak değiştirebilme.
